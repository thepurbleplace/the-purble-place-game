# The Purble Place – Classic Mini-Games Guide & Browser Play

Welcome to the **[The Purble Place](https://thepurbleplace.com/)** resource hub! Originally loved as a classic Windows casual game collection, **Purble Place** brings together three colorful, brain-teasing mini-games designed for players of all ages.

## The Three Classic Mini-Games

* **Purble Pairs:** A fast-paced pattern recognition and memory card-matching game with special bonus tiles, sneak-peek clues, and progressive grid sizes.
* **Comfy Cakes:** A fun bakery assembly-line challenge where you match cake shapes, batters, icings, and toppings against incoming customer orders before time runs out.
* **Purble Shop:** A classic logic and deduction puzzle where you uncover the hidden facial features of a Purble character using limited guesses and color-coded clues.
